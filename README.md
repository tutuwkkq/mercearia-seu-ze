# Desafio Digital - Mercearia do Seu Zé

Repositório oficial desenvolvido para estruturar a presença digital da tradicional Mercearia do Seu Zé, unindo a tradição de mais de 40 anos no Centro de Curitiba com a inovação voltada para os novos moradores e universitários.
